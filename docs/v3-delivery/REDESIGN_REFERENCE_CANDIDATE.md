# 新界面与输入参考候选

2026-09-24，基于已发布的 0.5.4，分支 `design/reference-dimensions`。这是可体验的源码候选，没有覆盖正式版或发布更新。

## 界面和交互

- 维持已确认的蓝紫 / 雾蓝灰语言。手机主页面分为连接、草稿、图片工具、插入状态；主要入口使用图标和短文本。
- 浮窗正文、情绪、参考、交付操作各有独立空间。恢复和收起在顶部；摘要/语气/附注及操作按钮空间不足时换行。
- 展开页内容可滚动，底部复制、插入、返回浮窗独立保留；辅助操作自动换行。设置表单长行可以换行。
- 手机低高度编辑页可滚动，返回/保存保持顶部可访问；更多工具、图注不会被隐藏容器裁掉。
- 窗口变化时动效边框跟随实际尺寸。保留语气图标、愤怒火焰和输入动效。

## 输入参考

目标、信息、上下文、结果四项等权展示，没有总分或成功率。显示可辨识、大致可辨、依赖上文、可能有歧义、暂无法判断等观察，不给用户下指令。不确定项不会阻止复制/插入，不会自动改写正文。

仅发送当前文字。明确显示“本段参考 · 未读取上文”，未读取图片、目标 Agent 对话或执行结果。历史提示词与历史结果的对应分析尚未接入，当前本地历史只有稿件与交付记录，不能冒充目标 Agent 的执行结果。

语气独立于这些维度。愤怒、粗口、简短表达不能直接导致负面参考。原有疑似转写错误与可选语音附注保留。

## 动态图形更新

输入参考已换成四轴节点图：勾表示可辨识、链条表示依赖上文、问号表示歧义、空心表示未知；暂定状态使用不同符号。轴长固定，不用面积、轴长或百分比冒充成功率。仅保留维度短标签，悬停可查看完整说明。结果变化时短暂动画，稳定后停止；关闭动效时立即显示静态结果。

手机同步显示手机到电脑的轨迹，图片使用实际上传字节进度。文字已同步但图片失败或未完成时，不显示全部接收完成。保留必要错误短提示和无障碍完整说明，情绪图标及火焰继续保留。

`graphics/reference-chart.gif` 是实际 Qt 浮窗录制，使用合成状态演示切换，不代表某段用户输入的实时评估。`graphics/phone-sync.png` 来自连接实际桥接的正式手机页面。

图形更新验证：35项相关界面/编辑/动效回归通过；64项布局、正式页面、统一交互和运行时检查通过。手机仍需实体设备体验。
