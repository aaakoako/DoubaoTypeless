## 两项修复

1. 手机一键清空当前文字及全部图片。原稿和新空稿在同一 IndexedDB 事务中保存，可从“最近”恢复；离线可用。清空使旧回执、迟到照片解码、旧截图结果与上传 checkpoint 失效。存储失败保留原稿并可重试；空状态重置不覆盖上次恢复副本。
2. 先逐图 Ctrl+V，再正文 Ctrl+V。之前每张图都等待附件接收证据，缺证据即结束，造成用户在 Codex 只看到图片。现在上传完成和附件识别不再阻塞后续粘贴；仍逐步检查同一目标、修饰键、剪贴板与取消状态。仅发键证据记作 injected/UNKNOWN，不冒充接收确认，不自动 Enter、不自动重复贴图。

清空不撤回已经贴到电脑的内容，不能取消已发到电脑且开始执行的插入。全部计划步骤正常发出且当前稿未修改时，保全完整历史后开始下一段；真正中断或失败保留当前稿。

当前蓝紫视觉、浮窗拖动/置顶/展开返回、设置共存、白板编辑、排序及独立确认发送继续保留。
