## 本轮产品改进

- 固定安装入口、版本标识和数据目录；升级前备份持久数据，旧程序版本保留，卸载保留用户内容；支持文件被占用后重试及跨目录旧卸载器保护。
- 手机返回键可退出面板和编辑器；未保存白板需确认放弃；小视口下保留插入、取消及文字添加入口。
- 浮窗在屏幕变化后恢复到可见区域；设置隐藏时仍更新手机在线状态，连接恢复不会擅自唤起已收起的浮窗。
- 截电脑按 Windows 主显示器标记选屏；测试经过真实截图按钮与屏幕采集，不再用相册图片冒充截图。
- 新稿清除上一轮插入提示；晚到回执明确标作“上次插入”，不误称新稿已经发送，不清除后来编辑的文字。
- 保持此前蓝紫视觉、浮窗拖动与置顶、人工滚动不被打断、展开返回、设置共存、主动恢复、白板工具及图文顺序。
