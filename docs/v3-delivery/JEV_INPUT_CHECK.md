# 0.5.0 输入检查与交互动效

「常用设置」中的 Jev 支持 TypeSafe、Vercel AI Gateway、OpenRouter 和 TypeSafe 兼容自定义接口。各服务商 Key 独立保存在系统凭据库；系统凭据不可用时只在当前会话保存。模型默认不开启，不内置任何人的 Key。纠错与改写是独立的 OpenAI 兼容模型配置，不把 Jev 当作 Chat Completions 模型。

自定义地址支持域名、Base URL、完整接口、末尾斜线、V1、Completion 等常见格式；补全后显示实际地址。完整自定义接口保留原路径。更换主机后清除未重新输入的 Key；不跟随重定向。检测连接只发送固定示例，启用后只发送当前稿文字，不发送图片、历史或词库。

浮窗使用 SVG 图标加短标签，展开查看原句。可选附注固定为「【输入说明：以下文字可能含语音转写或表述误差。】」，不要求目标模型追问。误判时可为本段取消，同段修改不自动重开；原稿及恢复保留原文。等待、失败或旧结果都不阻挡复制和插入。

## 动效

用户明确要求应用不跟随 Windows 减少动态效果。默认开启，桌面常用设置与手机设置分别可关闭。提供文字到达波形、输入边框反馈、短暂愤怒火焰、点击涟漪、面板入场、新图片入场与同步光带。文字到达不等同于正在录音，提示明确说明此区别。

Qt 视觉层不拦截鼠标、不改变按钮命中区域，不修改正文、滚动或选区；窗口隐藏时停计时。火焰在正文外沿，四秒后保留静态暖色边框。手机设置会跨刷新保存，关闭会移除所有动画。真实Qt/生产网页离屏渲染与模型判断分别取证，不把构造的语气截图当成模型输出。

## 候选回归中发现的启动竞态

524a802 的发行前验证通过，但独立 CI Windows 的旧有延迟监听测试出现失败。本地连续运行在第 12 轮复现：控制日志中客户端 connected 早于服务端 listening 日志，之后没有 received，客户端在期限内未获得回执。

QLocalServer 原生监听启动与 newConnection 处理器注册之间已经可能收到连接。修复在注册处理器后立即排空已有待处理连接；保留逐连接完成标记和回复写出后再执行，不重发命令、不扩大期限。新增真实跨进程 show/quit 提前连接回归；移除修复的运行反证两项均失败，带修复五项均通过。独立只读复核未发现重复分发或资源归属问题。

新界面测试另有一次 Linux 失败，原因是设置保存路径调用 Windows 全局热键。界面测试现在明确替换 OS 热键注册，继续执行真实设置保存及 Qt 控件；原生快捷键行为由既有 Windows 候选验证覆盖，不冒充 Linux 原生热键已验证。
