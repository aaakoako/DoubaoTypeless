# 图文焦点恢复的输入来源验证

图片上传界面可能自动聚焦附件，恢复正文输入不能只比较 GetLastInputInfo。该值包含本应用的 SendInput，而且不保证时间单调，详见[微软说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getlastinputinfo)。

图文事务现在使用短生命周期观察器：本应用注入带随机标记，其他键盘或鼠标输入仍记为外部活动。只记录计数，不记录键值、坐标或正文。恢复仅限原窗口和原附件容器，最多三次恢复焦点，不重发图片；扫描前后检查输入状态，结束或异常均释放观察器。无法观察时不自动恢复。

独立审查找到并修复两处时序：时间戳必须先于计数屏障读取；首次阻塞屏障必须放在最终目标校验之前。确定性回归分别验证用户在采样间点击时不调用恢复，以及屏障期间切换目标时不注入任何内容。

[原生诊断35908543979](https://github.com/aaakoako/DoubaoTypeless/actions/runs/35908543979)固定加载23d2b7d源码，在一次性64位Windows环境取得以下结果：

| 事件 | 发送标记 | hook收到标记 |
| --- | --- | --- |
| 键盘 | 0x4f12345676543210 | 0x4f12345676543210 |
| 鼠标 | 0x4f12345676543210 | 0x76543210 |
| 键盘与鼠标 | 0x76543210 | 0x76543210 |

因此随机标记限制为非零31位，并继续完整值比较；不把任意外部64位标记截断后认作自身。诊断只记录来源标记和injected布尔值。真实CI测试保留自身/外部键鼠分类断言，仅在一次性Windows桌面运行；普通本地跳过，避免干扰用户。

故障恢复的独立诊断35906340222在两台干净Windows环境均通过，原20/60秒限制和断言不变。原共享runner发生的PowerShell/安装入口超时根因未确定，保留失败记录。发行工作流将故障恢复放到独立runner，作为打包必需依赖，并绑定源码SHA、安装模板和辅助脚本哈希；测试失败不能发布。

这份诊断不替代最终固定提交的完整图文、安装、实际0.4.2升级、下载产物验证，也不代表Cursor或实体手机已验收。
