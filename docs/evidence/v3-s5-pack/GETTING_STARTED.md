# V3 预览入门（隔离候选，不是日用替换）

1. 不要覆盖日用安装里的 `config.json` / `data/`。
2. 解压 onedir 后双击 `DoubaoTypelessV3Preview.exe`（控制台）或 `DoubaoTypelessV3PreviewUI.exe`（无控制台）。
3. 用手机浏览器扫窗口里的二维码。电脑批准插入/截图。不必打开 `pc.html`，不必读 `pair.txt`，不必改 JSON，不必设环境变量。
4. 手机说一段 → 电脑看清或改字 → **插入并复制** → 窗口收起 → 手机新段落 → 上次可恢复。
5. 不配模型也能用文字、图片和白板。词库可从日用词典只读复制进本预览。
6. 「检查更新」只打开公开下载页，不会覆盖日用或本预览。
7. 关闭窗口到托盘；托盘「退出」才结束。再双击同一 EXE 唤起已有实例。

真机豆包输入法和真实 Cursor Composer 需要设备持有者验证。HTML 设计板不是产品完成。
