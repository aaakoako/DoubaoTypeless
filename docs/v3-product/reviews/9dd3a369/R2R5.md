# 9dd3a369 R2–R5 实现记录

对照独立复核 F03–F12。本目录不把缺设备的项写成 PASS。

## R2 图像闭环

- `asset_refs` 由 `resolve_asset_refs` 从已落盘对象解析，拒绝客户端 `assets` 对象。
- 资产写入 `{id}.meta.json` 保留 role；冻结时若同时有 screenshot/source 与成品，丢掉源图。
- 手机读图走带头 `fetch` → blob URL，离开时 revoke。
- HTTP 局域网用 `sha256Bytes`，不依赖 `crypto.subtle`；UUID 用 `getRandomValues`。
- 默认分块 512KiB，HTTP `client_max_size` 2MiB；1MiB 单块 PUT 不再 413。

## R3 浮窗 / 目标 / 恢复

- HUD 非 GUI 线程走 `QTimer.singleShot`。
- 投递比较完整焦点元组（含 HWND），同类不同窗口会停。
- 远端 unknown 目标拒绝；本机文字插入仍可走普通输入框。
- Alt+I 冻结当前稿；UNKNOWN/PARTIAL 进恢复选择；NO_STEPS 的 Alt+Shift+I 在新目标重试。
- `remaining_verified` 跳过已 observed 的图。已执行步骤不再回成 NO_STEPS。

## R4 编辑与设置

- 笔画/形状在落笔前记 undo。
- 双指同时缩放和平移。
- 无 `data_dir` 的 ACK `durable=false`；有目录则先 `save_draft` 再 durable。
- BYOK 默认 httpx transport；返回后重读当前 draft 版本。
- 手机设置页读取 `/v3/status` 和当前授权，密钥仍只在电脑。
