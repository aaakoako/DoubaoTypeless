# 原型说明与使用范围

用现代浏览器打开index.html；单文件、无外链脚本、不要求Key、不上传文件。本原型用原生Canvas演示交互，**不是拟采用Konva生产实现**。演示页外侧的电脑工作区、状态切换条和故障按钮不是产品主界面。

## 实际可操作

在普通输入框写字；浮窗出现/6秒隐藏/900ms结果隐藏；相册读取PNG/JPEG/WebP；同一画布上的画笔、记号笔、荧光笔、箭头、方框、椭圆、编号、文字、实心遮挡、近似命中橡皮和对象移动；撤销重做；拖出选区执行真实裁剪；缩放与适配；白板线框；PNG导出；从编辑器补充说明并返回原稿。

## 明确模拟

截电脑使用生成的技能卡样图，不读取真实屏幕。连接/断线/目标焦点/图像接收/文字粘贴使用演示状态，不调用系统剪贴板或键盘。投递中的短延时只用于演示状态推进，不是生产“等待附件就绪”的算法。不会联网、不会调用模型、不会建立真实配对、不会加密持久化。

## 尚未达到生产规格的地方

裁剪以重新拖选代替完整8手柄/比例/90°旋转控件；对象只有简化移动、没有完整缩放和精确命中；多指手势只作基础示意，未在手机实测；颜色/删除的部分触控命中区小于正式44px要求；文字工具使用浏览器prompt而非最终键盘抽屉；没有图序拖拽/撤销删除/完整编号说明绑定；设置/权限/最近列表使用示意抽屉或静态状态板；没有IndexedDB持久化、图片压缩worker和安全上传。

相册读取在原型中会先通过浏览器解码再检查像素尺寸，不能用于生产的安全尺寸检查。原型错误恢复通过选择器模拟目标，不代表可以只识别进程名就准确插入Cursor。刷新页面会丢失本原型数据；不要放需要长期保留或敏感的材料。

## 推荐演示顺序

空闲→输入文字→停止6秒观察隐藏→截图标注→画箭头/裁剪→完成→插入演示Composer→把目标改“代码区”→尝试插入→重新选择Composer→召回上次。再试“图完成、字未贴”和“图像接收未知”，观察只补文字与完整重贴的区别。

`tools/check_prototype.py`仅检查这个原型。Windows非激活窗口、真实手机输入法、真实Cursor附件接收都仍未验证。
