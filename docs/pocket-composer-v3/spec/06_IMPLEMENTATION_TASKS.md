## 风险前置的执行策略

V3-00冻结基线；V3-01与02验证真实Windows/手机能力，尤其Cursor焦点和附件就绪。如果不能可靠观察附件，先给出能力报告与半自动降级，不得在开发到最后才发现一键投递不可验证。03的纯核心可并行准备，但01/02未闭合时不扩大界面框架迁移。

03–09保住轻量文字路径。10–16完成截图/相册/画布/白板/图后文/重试闭环。17–19补足持久化、BYOK、引导设置。20–23完成性能、构建、独立验收和交付。白板在本轮内，隧道与新平台不纳入。

每张卡不允许全项目顺手重构。Bug来自别卡先建清晰复现，提交最小修复后重跑两卡受影响用例。所有平台验证缺口留在阻塞表，不把后续任务全部标通过来掩盖。
