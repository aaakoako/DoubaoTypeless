# 05 · 安全、轻量预算、故障与迁移

## 1. 信任边界：不能把局域网说成自动安全

本工具可能接触私密截图、工作代码和输入内容。手机输入法自身可能使用其云端服务，本应用“不上传音频”不能等同“整个语音过程不走云”。本应用默认不自动向模型发送图片或正文，只有可选手动BYOK文字纠错另有网络出口。

继承现有HTTP局域网方式可作为**可信私人局域网模式**，但必须在第一次配对清楚提示：未加密传输可能被同网络攻击者窃听/篡改，配对不能解决网络窃听。公共Wi-Fi、跨公网或敏感材料场景不得以此模式宣传安全。HTTPS/WSS为后续安全连接配置方向；不要求第一版自行发明端到端加密协议，也不指导用户关闭浏览器证书校验。[S11]

公网隧道、路由器端口转发默认不支持；绑定0.0.0.0也不意味着允许公网来源。按所选局域网接口提供地址与访问策略，拒绝未授权Origin/Host和非预期网络来源。只有本地127.0.0.1设置界面不需要手机功能的广域访问。

## 2. 配对、截图、插入权限分开

扫码携带一次性高熵配对挑战，2分钟失效，一次成功即作废；电脑显示新设备请求供确认。记住设备可明确选择30天，默认本会话8小时。设备凭据存手机受限存储、可撤销；HTTP环境下仍有窃听风险，不能把它叫强网络安全。

设备权限分别为草稿/图像同步、手机发起截图、手机发起插入。手机远程插入只允许前台已验证目标；第一次启用说明风险并由电脑确认。手机截图首次选择显示器并授权；不允许网络消息传按键脚本、shell命令、文件路径或任意进程句柄。

WebSocket验证Origin、会话、消息schema和频率；令牌不写query/log。WS鉴权首帧有5s截止，在鉴权前不计为已连接设备、不收正文。HTTP上传需要同设备授权，禁止通配CORS；Cookie路线须加CSRF机制，不由实现者随意混搭。重连不恢复过期权限、不自动执行截图或插入。[S11]

## 3. 图片和隐私

导出只发送处理后的扁平化像素；编辑源图/图层默认不交给Agent。不同时附原图，尤其裁剪/遮挡后。遮挡必须是实心像素覆盖，导出测试通过解码结果检查被遮区域；不宣称普通荧光笔、马赛克或模糊等价不可恢复脱敏。

手机本地图像可被浏览器清理；用IndexedDB存草稿并显示保存状态。电脑近期图片/文本建议以系统凭据库保护的应用数据密钥进行本地加密存储；密钥库不可用则默认会话内存模式，并明确提醒重启不可恢复，不能悄悄把Key写进JSON。不得将密钥随可分享诊断包/ZIP导出。

删除仅承诺移除本应用记录及其无引用文件；无法保证SSD/备份/系统剪贴板历史/目标应用副本的法证擦除。剪贴板同步/历史可能被操作系统或第三方收集，首次引导给予说明。

## 4. BYOK和术语只保留一个旁路

默认没有自动模型请求。设置仅provider/base URL/key/model和“测试”；高级参数折叠。Key存在系统凭据库，不到手机、不入截图、不写日志。更换endpoint主机先清空Key关联或明确重新授权，禁止带旧Key到新域名。

只支持经过适配的Chat Completions兼容路径作为首批范围；“兼容”不等于所有厂商都接受相同temperature/response格式。测试错误区分DNS/TLS/401/403/404/429/超时/格式；不凭错误猜用户余额。请求总预算8s，失败保留原文且插入从未被禁用。

词库：`O PU S→Opus`由用户确认后可本地规则；`Midjourney→Image2`因语义冲突默认仅提示。语音输入法给的文本才是实际输入，无法靠后处理可靠还原原始录音。接受一次不等于永久记录；只在“记住改法”动作后存词条。代码/URL/路径等保护区默认不自动改写。

AI响应绑定draft_id/epoch/revision/hash；期间改稿、插入或切换稿件则旧响应不能应用。只显示局部差异并逐条采纳，不全稿覆盖。后台学习队列不自动迁移运行。

## 5. 轻量性能预算（均是目标，必须测，不是现状）

| 场景 | 目标 | 测量方法/不通过怎么处理 |
|---|---|---|
| 电脑空闲 | 桌面可见浮窗0；CPU中位≤0.3%、P95≤1%（任务管理器式总CPU归一化）；Private bytes≤180MiB目标、超过250MiB需阻止扩大 | 普通4核以上16GB机器，候选包预热后采样10分钟，记录硬件/电源模式/系统版本 |
| GUI唤醒 | 文字到达至首次HUD绘制P95≤100ms | 本机monotonic打点；原生记录，不含输入法识别时长 |
| 局域网文本同步 | 页面input事件至电脑接收并展示P95≤150ms目标 | 两端时钟不同不得直接相减；用关联ACK往返和校准误差分开记录 |
| 绘画反馈 | 单笔响应目标≤32ms P95；60Hz下尽量稳定，连续慢帧有记录 | 390×844手机、2MP图、200笔；桌面浏览器模拟不能替代手机 |
| 导出/上传 | 常见2560长边图导出≤1s目标；慢设备有进度/取消 | 本地导出与网络耗时分开，不能把等待伪装为卡死 |
| 纯文插入 | 目标通过后到发键P95≤150ms，不含用户释放修饰键 | 独立观测回执，不把文字确实进入目标计为无证据完成 |
| 包体 | Windows便携ZIP≤150MiB目标 | 实际锁依赖后测；不承诺PySide6一定达标，禁打包WebEngine/开发工具 |
| 网页资源 | 输入首屏JS gzip≤150KiB目标，画布按需加载≤500KiB目标 | 构建统计；首次纯语音不加载整个编辑器 |
| 稳定性 | 200轮图文链路、连续2小时使用，无丢稿/错误清理/双重投递 | 保存每轮状态和失败；非零错误不靠平均值掩盖 |

隐藏时停止动画/逐帧渲染；网络保持合理心跳，不轮询截图；截图按需，不常驻屏幕帧；一次只解码当前图并缩略其他图片。性能不通过先剖析和裁剪依赖，不直接再换一整套框架。

## 6. 出包与迁移

候选版使用独立配置目录，例如用户应用数据下DoubaoTypeless/preview-v3；不要与日用v0.4.2同端口/同热键同时抢资源。检测旧进程，提示退出或临时禁用候选热键，不杀旧进程。

迁移读取旧config.json/dictionary/历史，先脱敏预览再确认；保留旧文件原样、备份和迁移版本号。Key迁入凭据库成功才清理新JSON里的Key，绝不删除旧用户备份而不告知。旧图片不存在时不要伪造新记录。后台learn开关迁移为停用归档，不能自动耗费旧Key。

候选Windows便携包单独打包，由Windows runner构建；Linux上的Python测试不能生成经过Windows验收的EXE，PyInstaller不是跨平台交叉编译器。[S12] 本轮不覆盖稳定Release、不推v*标签触发现有直接发布流程。

构建应先npm ci + 前端测试/构建，再Python测试/静态检查，再PyInstaller onedir；Qt资源、网页资源、图标、许可证、锁文件和版本信息纳入制品。上传workflow artifact作为候选，不把“打包成功”标为运行验收。最终至少干净Windows机器启动、真实手机扫码、截屏、标注、先图后文、错焦点恢复、重启召回通过。

回退：退出候选，重新启动原稳定版；旧数据未被原地写坏。候选迁移失败能重复尝试且不会复写坏数据。所有公开发布需用户明确授权；本方案不授权开发模型自动merge/tag/release。
