## 执行步骤与可观察结果

1. **三种笔刷**：同图绘圆头笔、记号笔、荧光笔并导出。完成后必须观察：线宽/不透明度符合，荧光笔一笔内部不叠加变黑。验收层级：真机，对应 `AC3-049`。
2. **几何与橡皮**：箭头、矩形、椭圆、文字、编号→移动→橡皮→撤销。完成后必须观察：底图不被擦除；对象可恢复；文字中文正常。验收层级：自动+真机，对应 `AC3-050`。
3. **指针取消**：绘画中第二指加入/系统pointercancel/离开边界。完成后必须观察：无幽灵笔画，无卡死；下次单指仍能画。验收层级：自动+真机，对应 `AC3-051`。
4. **撤销重做**：连续50步混合绘画裁剪删除，撤销重做，新画一笔。完成后必须观察：新分支清redo，不清现有图；达到预算只丢旧Undo能力。验收层级：自动，对应 `AC3-052`。
