1. **错焦点重试**：在代码区第一次失败，点Composer按Alt+Shift+I。完成后必须观察：召回上次固定图文，以新目标完整重试。验收层级：Windows，对应 `AC3-065`。

3. **未知恢复**：在sent后崩溃重启；或更换输入文档再重试。完成后必须观察：不自动重放；显示恢复选择，不自动Ctrl+A/Delete。验收层级：Windows，对应 `AC3-067`。
