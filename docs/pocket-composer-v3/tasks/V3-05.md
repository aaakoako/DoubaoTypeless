1. **大图断点续传**：上传4MiB图到一半断开再恢复。完成后必须观察：只补缺块，SHA256吻合后ready；不重复资产。验收层级：自动，对应 `AC3-021`。
2. **恶意或超限资源**：文件扩展名伪装、错误哈希、超20MiB、超48MP、路径穿越名。完成后必须观察：拒绝并删除临时残留；没有内存失控/任意路径写入。验收层级：自动，对应 `AC3-022`。
3. **磁盘满**：模拟fsync/rename/DB提交失败。完成后必须观察：无durable ACK，手机仍保留素材，可重试。验收层级：自动，对应 `AC3-023`。
4. **版本与GC**：旧render迟到且新图在Attempt中，同时执行清理。完成后必须观察：旧图不替换新图，有引用图不被删除。验收层级：自动，对应 `AC3-024`。
