1. **手机截电脑**：首次批准显示器1，此后手机点截电脑。完成后必须观察：只有指定显示器当前帧进入手机，不截全部屏幕。验收层级：Windows+真机，对应 `AC3-041`。
2. **区域截图**：热键区域选择后取消一次再完成一次。完成后必须观察：取消无新图片；完成正确区域，HUD不出现在截图。验收层级：Windows，对应 `AC3-042`。
3. **DPI坐标**：不同DPI屏幕跨边界选区/负坐标显示器。完成后必须观察：像素范围与选择一致，无缩放错位。验收层级：Windows，对应 `AC3-043`。
4. **过期隐私**：锁屏、权限撤销、过期request、快速连点。完成后必须观察：拒绝/限流；无周期截图，恢复前台不补拍。验收层级：自动+Windows，对应 `AC3-044`。
