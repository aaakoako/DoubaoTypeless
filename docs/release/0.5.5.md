# 0.5.5 Preview · 正文优先 / Input first

## 中文

本次重点是让输入重新成为界面中心。手机页面、电脑浮窗和展开页重新整理了层级，辅助内容按需出现。

- **正文优先**：增大浮窗阅读区域，辅助操作按空间换行；展开页可滚动，主要操作保留在底部。
- **可选Jev**：默认关闭。开启后仅显示轻量参考标记及语气，完整动态参考图主动展开；没有总分或成功率。
- **图形反馈**：手机到电脑同步轨迹、实际图片上传进度、输入动效，以及保留的愤怒火焰彩蛋。
- **布局修复**：大字号按钮、低高度白板工具、显隐状态和窗口变化时的动效边框。
- **许可与文档**：中英文产品介绍，MIT商用条件，随包第三方声明和实际依赖清单；排除不使用的Qt虚拟键盘模块。

安装包用于当前用户；便携ZIP必须完整解压。Jev和改写模型均需自行配置服务，核心图文输入不依赖API。

这是体验候选，不替代稳定版0.5.4的默认更新。界面截图采用合成内容。实体手机输入法、多屏、Cursor及所有目标Composer并未逐一验收；参考只看当前文字，不读取目标Agent历史。正常插入不会自动发送消息。

## English

This preview puts the draft back at the center. The phone composer, desktop overlay and expanded editor have a clearer hierarchy, with assistance shown on request.

- **Input first:** more reading space, wrapping actions, scrollable expanded content and a separate primary-action area.
- **Optional Jev:** off by default. Compact reference/tone markers expand into a dynamic diagram on request. No overall score or predicted success rate.
- **Visual feedback:** phone-to-desktop sync trace, actual image-upload progress, input motion and the preserved anger-flame easter egg.
- **Layout fixes:** large text, low-height whiteboard tools, hidden-state handling and animation borders after resizing.
- **Licensing and docs:** bilingual product pages, MIT commercial-use terms, bundled dependency notices and an exact component inventory; unused Qt Virtual Keyboard excluded.

Choose the per-user installer or fully extract the portable ZIP. Optional model services use your own configured credentials; core text/image input does not require an API.

This is a preview, not a replacement for the default stable 0.5.4 update. Visuals use synthetic content. Physical mobile keyboards, multi-monitor setups, Cursor and every target composer have not all been accepted. References see only current text, not target-agent history. Normal insertion does not automatically send a message.
