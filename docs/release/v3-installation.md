# 安装与使用 DoubaoTypeless 0.5.0

安装包和便携包包含同一套 Windows 客户端与手机页面。版本标注“发布候选”时，仍需完成真实手机和目标输入框验收；这不代表已经公开发布。

## 开始使用

1. 从旧版托盘正常退出，保留旧目录和数据。
2. 运行 `DoubaoTypeless_0.5.0_win_x64_Setup.exe`。仅为当前 Windows 用户安装，无需管理员权限。以后从开始菜单打开 **DoubaoTypeless**。
3. 手机与电脑接入同一网络，扫描电脑连接页的二维码。地址和端口以该页为准，不沿用旧预览端口。
4. 在电脑连接页允许手机插入。点一下 Codex/Cursor 的对话输入框，再用手机说话、加入图片，点“插入电脑”。插入不会自动发送消息。
5. 插入后手机可开始下一段。需要上一段时使用“恢复”；不要重复点插入来猜测图片是否已经进入目标。

浮窗标题可以拖动；阅读旧文字时不会强行滚到底部。展开后可以返回浮窗，设置窗口和浮窗可同时显示。白板文字在页面内编辑，可以取消；手机返回键会关闭当前面板，未保存白板会先询问是否放弃。

## 数据与升级

正式安装与发布候选默认使用 `%LOCALAPPDATA%\DoubaoTypeless\workspace-v3`，不随安装版本目录变化。旧预览数据与旧版 `config.json` 不会自动导入或覆盖。需要保留已有预览内容时，先在原版本完成当前稿或导出词库；不要直接把多个版本的数据目录混在一起。

设置中的“数据与备份”可以打开当前目录。升级首次启动会在 `upgrade-backups` 保存当前草稿、图片、设置、恢复记录及本地持久文件；SQLite 通过备份接口保存。只把含有 `backup-complete.json` 的目录视为完成备份。正常安装的 API Key 存在 Windows 凭据库，文件备份不包含该密钥；固定工作区内升级会继续使用已有凭据。

升级安装后，先退出旧进程，再从开始菜单打开新版本。安装目录中的 `versions` 会保留此前安装的程序，便于回退同一数据格式的版本。未来数据格式不兼容时，旧版本会拒绝修改数据。

需要恢复备份时，退出程序，保留当前工作区副本，再把一份完整备份放到独立目录，用程序的 `--data-dir` 参数打开核对。凭据与 Windows 账户及工作区路径绑定，换目录或换账户后需要重新填写 API Key。不要在运行中覆盖工作区。

卸载只移除程序和当前安装对应的入口，保留用户数据。文件被占用时会提示退出程序后重试，并保留卸载入口。便携包解压后直接运行 `DoubaoTypeless.exe`，同样使用固定工作区。

## 遇到问题

- 找不到输入框：先手动点一下目标对话框，再插入。若已复制，可以在目标按 Ctrl+V；不要按 Enter 试探。
- 图片接收待确认：查看目标中已有图片，使用“恢复”处理剩余内容，避免重复插入。
- 手机断线：继续保留手机页面，草稿会在本地保存；电脑已收到的稿仍可使用。重连后按页面提示恢复。
- 版本不一致：核对电脑连接页和手机设置中的版本号及提交标识，退出旧程序后重新扫码。
- 升级失败：保留数据和 `upgrade-backups`，使用“导出诊断”提供错误记录；不要删除工作区来解决启动问题。
