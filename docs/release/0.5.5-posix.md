# Pocket Composer 0.5.5 — macOS / Linux 体验版

手机输入文字、图片和白板，电脑选中输入框后插入。模型分析仍为可选功能，默认关闭。本次新增 macOS 与 Linux 安装包，Windows 稳定版仍为 0.5.4。

| 系统 | 文件 |
|---|---|
| Mac · Apple Silicon（M 系列） | `PocketComposer_0.5.5_macos_arm64.dmg` |
| Mac · Intel | `PocketComposer_0.5.5_macos_x64.dmg` |
| Ubuntu 22.04+ x64 · X11 | `PocketComposer_0.5.5_linux_x64.deb` |
| Linux x64 便携目录 | `PocketComposer_0.5.5_linux_x64.tar.gz` |

[安装、权限和限制说明](https://github.com/aaakoako/Pocket-Composer/blob/master/docs/release/CROSS_PLATFORM.md)

- Mac：把应用拖入 Applications；自动插入需要辅助功能权限，截屏需要屏幕录制权限。本包尚未取得 Apple Developer ID 签名和公证，首次运行请按系统提示单独授权，不要关闭系统全局安全检查。
- Linux：建议使用 DEB 安装，自动安装运行库。自动插入依赖 X11 与 AT-SPI；Wayland 当前仅支持编辑、同步和复制。
- 先点中目标输入框，再从手机插入。目标不可识别或插图后焦点改变时保留稿件，不向未知控件盲贴。插入不会自动发送 Enter。
- 密钥使用 macOS 钥匙串 / Linux Secret Service；密钥环不可用时仅在当前运行中保留。登录自启动暂未提供；升级请退出后用对应新包替换应用，保留数据目录。
- 随包保留依赖版权声明；Linux 系统库另附 `licenses/linux-system-components.json` 与上游版权、源码来源。应用代码仍采用 MIT，依赖各自遵守原许可证。

## 验证与范围

- 三种架构的原生包已通过构建、Cocoa / X11 启动、HTTP 页面和 IPC 正常退出检查，以及包内库链接完整性检查。
- 独立 Linux X11 桌面的真实 Qt 接收窗口收到图片后接文字，截图与剪贴板读写通过；这不代表已验证所有 Agent。
- macOS 已检查原生辅助功能 / Quartz API，但尚未完成真实授权后的 Codex/Cursor 图文插入验收。实体手机、多屏和目标应用兼容性仍需体验反馈。
- `SHA256SUMS.txt` 可核对四个包，`build-provenance.json` 记录源码版本与构建证据。

# English

This preview adds macOS (Apple Silicon and Intel) and Linux x64 packages to Pocket Composer. Compose text, images and whiteboards on your phone, then insert into the input you selected on your desktop. Optional model analysis remains off by default. Windows stable remains 0.5.4.

Choose the DMG matching your Mac's CPU, or the DEB / tar.gz for Linux x64. [Setup and limitations](https://github.com/aaakoako/Pocket-Composer/blob/master/docs/release/CROSS_PLATFORM.md).

**macOS:** drag the app to Applications, grant Accessibility for insertion and Screen Recording for capture. This preview is not Developer ID signed or notarized. Use the system's per-app approval, not a system-wide security bypass.

**Linux:** Ubuntu 22.04+ with X11 and AT-SPI. The DEB installs system dependencies. Wayland currently supports editing, sync and copy, but not automatic insertion, global shortcuts or capture.

Select the target input first. Unrecognized or changed targets stop with the draft retained. Insertion never automatically sends Enter. Keys use Keychain / Secret Service, with memory-only fallback. Login autostart is not yet provided. Quit before replacing the application to update; keep the user data directory.

**Validation:** native Cocoa/X11 frozen startup, HTTP, graceful IPC exit and packaged library-link checks passed. An actual Qt receiver on a disposable Linux X11 desktop received image then text; screenshot and clipboard checks passed. macOS native APIs were checked, but permission-granted Codex/Cursor insertion, physical phones and multi-monitor use are not yet accepted. These are experimental packages.

Check `SHA256SUMS.txt` and `build-provenance.json`. Dependency notices and source references are included; the application's MIT license does not replace dependency licenses.
